# Kulinarny Asystent

Strona internetowa pomagająca znaleźć pomysł na posiłek na podstawie typu posiłku (śniadanie, obiad, kolacja), rodzaju smaku (ostry, słony, słodki) oraz regionu kuchni (polska, włoska, chińska, ameryańska).

Strona zbudowana przy użyciu:
- HTML5
- CSS3
- JavaScript

Funkcjonalności JS:
- Wyszukiwanie i losowanie przepisów z bazy
- Rozwijane menu mobilne
